# qrrrv / GitHub portfolio

Нео-брутальное портфолио публичных проектов профиля [qrrrv](https://github.com/qrrrv).

Сайт собирает 25 публичных репозиториев, их языки, README-описания, звёзды и форки. В каталоге доступны поиск, фильтры по языку и прямые ссылки на GitHub.

## Запуск

```bash
npm install
npm run dev
```

## Обновление каталога

Данные проекта хранятся в `src/data/github-projects.json` и получены из публичных GitHub API-метаданных и README репозиториев.
