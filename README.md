# BRUTAL / by design

Одностраничный сайт-портфолио креативной студии в эстетике Neobrutalism.

## Запуск

```bash
npm install
npm run dev
```

## Структура

- `src/components/` — разметка и интерактивы
- `src/data/` — контент карточек и манифеста
- `src/styles/` — токены, базовые, компонентные и адаптивные стили
- `public/manus-routes.json` — манифест маршрутов WebDev
